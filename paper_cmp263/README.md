# Artigo / Relatório Final — CMP263 (UFRGS)

Esta pasta contém o relatório de pesquisa e artefatos preparados para a disciplina de **Aprendizagem de Máquina (CMP263 - INF/UFRGS)**.

## Formatos Disponíveis:

1. **Relatório Completo em Markdown**:
   * Arquivo: [`REPORT_CMP263.md`](REPORT_CMP263.md)
   * Contém o texto integral com todas as equações, tabelas de ablação, gráficos de alta resolução incorporados e referências. Ideal para leitura rápida, visualização no GitHub ou conversão direta para PDF via Pandoc/Typora/VS Code.

2. **Artigo em LaTeX (Padrão SBC - Sociedade Brasileira de Computação)**:
   * Arquivo principal: [`main.tex`](main.tex)
   * Arquivo de referências: [`references.bib`](references.bib)
   * Estilo e bibliografia SBC: [`sbc-template.sty`](sbc-template.sty), [`sbc.bst`](sbc.bst)
   * Figuras: pasta [`figures/`](figures/)
   * Pacote pronto para Overleaf: `../cmp263_paper_overleaf.zip`

3. **Reprodução 1-Click (Google Colab)**:
   * [Abrir Notebook de Replicação no Colab](https://colab.research.google.com/github/podorize/skillreuse/blob/main/notebooks/reproduce_in_colab.ipynb) (executa em ~45 segundos).
