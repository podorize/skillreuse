# Appendix B — Use of artificial intelligence tools

Claude Code \cite{claude_code} (Anthropic) was used as an implementation and analysis assistant throughout the project: dataset audit, target and feature construction, validation and tuning code, holdout construction, tests, figures and drafting. The authors defined the research questions, approved each methodological decision (owner-based target, excluded attributes, per-owner cap, protocol, holdout and single evaluation), reviewed the outputs and are responsible for the code, the claims and the interpretation. Automated tests check the numbers reported in the text against the result files.
