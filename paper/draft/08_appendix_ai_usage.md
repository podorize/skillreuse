# Appendix B — Use of artificial intelligence tools

OpenAI Codex \cite{openai_codex} was used in the early phases to plan the pipeline, assist code implementation and organize the text. In the revision that gave rise to this report, Claude Code \cite{claude_code} (Anthropic) was used as an implementation and analysis assistant: dataset audit, owner-based target and context features, owner-grouped validation, nested tuning, holdout construction, tests, figures and drafting. The author requested the critical review of the research design, defined the questions, approved each methodological decision (owner-based target, excluded attributes, per-owner cap, protocol, holdout and single evaluation) and is responsible for the code, the claims and the interpretation. The [usage log](../ai_usage_log.md) and the [AI supplement](../ai_usage_supplement.md) record the tasks and the verbatim prompts that are available, and state that the record is incomplete; no prompts from missing sessions were invented.

Relevant errors and limits of the assistance: (i) an initial "ecosystem effect" hypothesis for location was revised when the audit of occurrences showed the effect of the representative rule; (ii) the sharing of `name` was first reported with empty names included (37%) and corrected (20%); (iii) a first tuning run became infeasible because of memory and thread overload and was reconfigured with a reduced protocol; (iv) an earlier design treated the original external test as confirmatory and used attributes that depended on the representative rule, which was identified and corrected; (v) `push_recency_days` (days since the last push) was first read as higher recency, and a speculative explanation was offered for the license effect; the partial dependence showed the opposite direction and that the effect is the absence of a license, and both readings were corrected. The quantitative claims were reconciled with the CSVs and manifests of Appendix A; the bibliography still requires a final check before submission.
